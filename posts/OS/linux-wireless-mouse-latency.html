Linux（Ubuntu）使用无线鼠标有延迟的解决方法 ​

问题描述 ​

在 Linux（尤其是 Ubuntu）系统中使用无线鼠标（如 2.4G 接收器或蓝牙鼠标）时，可能会遇到鼠标移动不跟手、有延迟、掉帧甚至偶尔卡顿的情况。这个问题在树莓派等 ARM 设备上尤为常见，但 x86 平台的 Ubuntu 也可能遇到。

原因分析 ​

鼠标延迟通常与以下因素有关：

  1. USB 轮询频率（Polling Rate）：Linux 内核默认对 USB 设备采用较低的轮询频率，这会限制鼠标报告位置的频率，导致感知上的延迟。
  2. 无线信号干扰：2.4G Wi-Fi、蓝牙设备或其他无线外设可能产生干扰。
  3. 电源管理：系统的 USB 自动休眠策略可能会让无线接收器进入低功耗状态，唤醒时产生延迟。
  4. 桌面环境 compositor：某些桌面环境的合成器设置也可能引入额外的显示延迟。

本文主要解决的是 USB 轮询频率 导致的延迟问题。

解决方案 ​

方法一：修改内核启动参数（推荐） ​

通过在内核启动参数中添加 usbhid.mousepoll=0，可以让系统使用鼠标设备自身的轮询频率（通常为 1000Hz），而不是内核默认的较低频率。

步骤 ​

1. 找到启动配置文件

首先查看 /boot/firmware/config.txt（树莓派等 ARM 设备）或 /etc/default/grub（x86 设备）：

shell
# 对于树莓派等使用 config.txt 的设备
cat /boot/firmware/config.txt | grep cmdline
# 输出示例：cmdline=cmdline.txt

2. 编辑启动参数文件

shell
sudo vim /boot/firmware/cmdline.txt

注意：文件名可能与 config.txt 中配置的 cmdline=xxx.txt 一致，常见为 cmdline.txt。

在文件末尾添加以下参数（确保与已有参数用空格分隔）：

usbhid.mousepoll=0

完整示例：

console=serial0,115200 console=tty1 root=PARTUUID=xxxxxx-xx rootfstype=ext4 fsck.repair=yes rootwait usbhid.mousepoll=0

3. 重启系统

shell
sudo reboot

4. 验证是否生效

重启后，可以通过以下命令检查当前轮询间隔：

shell
cat /sys/module/usbhid/parameters/mousepoll

如果输出为 0，则表示配置已生效。

方法二：使用 modprobe 配置（临时/永久） ​

临时生效（重启后失效） ​

shell
sudo modprobe -r usbhid
sudo modprobe usbhid mousepoll=0

永久生效 ​

创建或编辑 modprobe 配置文件：

shell
echo "options usbhid mousepoll=0" | sudo tee /etc/modprobe.d/usbhid.conf
sudo update-initramfs -u
sudo reboot

方法三：调整 USB 电源管理 ​

如果延迟是由 USB 自动休眠引起的，可以禁用 USB 设备的电源管理：

shell
# 查看当前 USB 设备的电源管理状态
for f in /sys/bus/usb/devices/*/power/control; do echo "$f: $(cat $f)"; done

# 禁用所有 USB 设备的自动休眠（需要 root）
for f in /sys/bus/usb/devices/*/power/control; do echo "on" | sudo tee $f > /dev/null; done

要让设置永久生效，可以创建一个 udev 规则：

shell
echo 'ACTION=="add", SUBSYSTEM=="usb", TEST=="power/control", ATTR{power/control}="on"' | sudo tee /etc/udev/rules.d/50-usb-power-save.rules
sudo udevadm control --reload-rules

补充优化 ​

使用 evhz 测试鼠标轮询率 ​

可以安装 evhz 工具来实时查看鼠标的报告频率：

shell
# 安装 evhz
git clone https://github.com/ian-kent/evhz.git
cd evhz
make
sudo ./evhz

运行后移动鼠标，可以看到实时的轮询频率。配置生效后，数值应该稳定在 1000Hz 左右（取决于鼠标本身的支持）。

蓝牙鼠标的额外优化 ​

如果是蓝牙鼠标，还可以尝试：

shell
# 查看蓝牙连接参数
hciconfig

# 调整蓝牙连接间隔（需要 root，值越小延迟越低，但耗电增加）
sudo hcitool cmd 0x08 0x0013 <handle> <min_interval> <max_interval> <latency> <timeout>

注意事项 ​

  • mousepoll=0 表示使用设备的默认轮询间隔。如果你的鼠标本身质量较差，可能并不能完全解决问题。
  • 部分老旧无线鼠标的默认轮询率可能只有 125Hz，这种情况下即使设置 mousepoll=0 也无法达到 1000Hz。
  • 树莓派等设备的 USB 带宽有限，如果同时连接多个高带宽 USB 设备（如摄像头、外置硬盘），可能仍然会有延迟。
  • 修改内核启动参数前建议备份原配置，以便恢复。
