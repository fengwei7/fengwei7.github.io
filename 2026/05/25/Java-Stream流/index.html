    Java-Stream流

    • 对于单列集合，Collection有默认方法stream()
    • 对于双列集合，无法直接使用stream流，需要使用map.keySet()或map.entrySet()转换为单列集合
    • 对于数组，可以使用Arrays下的静态方法stream()
    • 对于零散数据，可以使用Stream接口下的静态方法stream()
