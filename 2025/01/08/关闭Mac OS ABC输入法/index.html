    macOS 移除 ABC 输入法（仅保留第三方输入法）

    背景说明

    在 macOS 中，即使用户只使用第三方输入法（如鼠须管/Squirrel、搜狗拼音、微信键盘等），系统在切换输入法时仍然会保留 ABC（美国）输入法，在以下场景可能造成困扰：

    • 按错切换快捷键时不小心切到 ABC，需要再切回来
    • 某些游戏或应用会强制切换到 ABC 输入法
    • 希望完全屏蔽系统自带输入法，保持输入体验的一致性

    注意：macOS 10.15+ 系统对输入法管理更加严格，完全删除 ABC 输入法可能导致某些场景下的输入问题。建议根据个人需求谨慎操作。

    方法一：修改 plist 文件（推荐）

    macOS 的输入法配置存储在 com.apple.HIToolbox.plist 文件中，通过编辑该文件可以移除 ABC 输入法。

    1. 打开配置文件

    2. 删除 ABC 输入法条目

    1. 依次展开 Root → AppleEnabledInputSources
    2. 找到包含 KeyboardLayout Name = ABC 的 item
    3. 选中该 item 后按 Delete 键删除

    如果删除后遇到问题，或者需要恢复 ABC 输入法，可以：

    方法一：从备份恢复

    方法二：通过系统设置重新添加

    1. 打开 系统设置 → 键盘 → 输入法
    2. 点击 编辑 → 添加输入法
    3. 选择 英语 → 美国（ABC） 添加即可

    常见问题

    1. 修改后输入法列表没有变化

    确保修改后注销并重新登录或重启电脑，仅重启输入法进程可能不生效。

    2. 某些应用强制切换到 ABC

    部分应用（尤其是游戏、Adobe 系列软件）会强制使用 ABC 输入法以确保快捷键正常工作。这是应用层面的行为，无法通过删除系统输入法解决。

    3. 登录界面或密码输入框无法输入

    如果删除了 ABC 输入法，在某些安全输入框（如系统密码框）可能会遇到输入问题。建议至少保留一个拉丁字母输入法。

    4. 文件修改后权限问题
